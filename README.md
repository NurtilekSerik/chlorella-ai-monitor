# Chlorella AI Monitor — школьный прототип

## Что входит
- `index.html` — адаптивный сайт, 3D-просмотрщик, график, история, CSV экспорт.
- `esp32_firmware.ino` — пример прошивки ESP32 для датчика Sensirion SCD40/SCD41.
- `schema.sql` — таблица Supabase и учебные политики доступа.
- `assets/bioreactor.glb` — сюда положите свою GLB-модель.

## 1. Подготовьте базу данных
1. Создайте проект в Supabase.
2. Откройте SQL Editor и выполните `schema.sql`.
3. В Project Settings → API скопируйте Project URL и anon/public key.
4. Не используйте `service_role` key в браузере или прошивке.

> Внимание: политики в `schema.sql` открывают чтение и запись всем, у кого есть публичный anon key. Это удобно для школьного прототипа, но не для публичного промышленного сервиса. Для более безопасного размещения перенесите запись ESP32 в Edge Function с секретом и ограничьте доступ к чтению.

## 2. Подключите 3D-модель
Скопируйте свой файл в `assets/bioreactor.glb`. Путь и имя должны совпадать. Если файл не найден, сайт покажет встроенную запасную модель. Для лучшего результата центрируйте модель в Blender и экспортируйте в GLB.

## 3. Настройте ESP32
1. В Arduino IDE выберите плату ESP32.
2. Установите библиотеки `Sensirion I2C SCD4x` и `ArduinoJson`.
3. В прошивке заполните `WIFI_SSID`, `WIFI_PASSWORD`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`.
4. Пример рассчитан на SCD40/SCD41 по I2C. Другие датчики требуют изменения кода.
5. По умолчанию GPIO 27 используется как переключатель состояния эксперимента: подключите кнопку/переключатель между GPIO27 и GND. Если его нет, измените логику `reactorOn` в коде.
6. Загрузите прошивку и откройте Serial Monitor на 115200 бод.

Плата и датчик должны быть подключены корректно; проверьте питание и уровни логики по документации конкретного модуля.

## 4. Запустите сайт локально
Не открывайте `index.html` двойным нажатием: браузер может блокировать загрузку GLB. Запустите локальный веб-сервер в папке проекта, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## 5. Опубликуйте сайт по интернет-ссылке
Можно использовать GitHub Pages, Netlify или Cloudflare Pages:
- загрузите `index.html` и папку `assets/`;
- включите публикацию сайта;
- откройте выданную HTTPS-ссылку на телефоне;
- нажмите «Настройки подключения» и введите Supabase URL и anon/public key.

Для постоянной настройки URL/key можно заменить пустые поля на заранее заданные значения в `index.html`, но публичный ключ останется видимым посетителям — поэтому используйте только anon/public key и корректные политики доступа.

## Что означают режимы и ограничения
- **Демонстрационный режим** создаёт случайные примерные числа. Они помечены как «Демо» и не должны использоваться как результаты эксперимента.
- **Реальный режим** показывает записи из Supabase, отправленные ESP32. Если таблица пустая, реальные данные не появятся.
- Переключатели на странице управляют только интерфейсом/меткой эксперимента. Они не включают физическую LED-ленту или насос. Для управления аппаратурой нужна отдельная схема, реле/драйвер, безопасная проводка и прошивка.
- LED в 3D-модели и пузырьки — визуальная анимация. Они не доказывают реальное состояние LED, аэрации или рост хлореллы.
- Сравнение «реактор включён/выключен» использует только реальные строки. Снижение CO₂ само по себе не доказывает, что причина — хлорелла: учитывайте вентиляцию, число людей, время и расположение датчика.

## Архитектура
SCD40/SCD41 → ESP32 → HTTPS REST API Supabase → `index.html` → метрики, график, история и сравнение.
