Подключение реальных данных

Введите URL проекта Supabase и anon/public key. Эти поля сохраняются только в памяти текущей страницы и не записываются в файл. Для постоянного подключения добавьте их в конфигурацию сайта перед публикацией.

Для учебного прототипа используйте публичный anon key с ограниченными RLS-политиками. Никогда не вставляйте service_role key в сайт или прошивку.
